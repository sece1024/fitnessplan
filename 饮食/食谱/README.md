## 厨具清单（所有食谱只使用这 5 件）

| 厨具 | 在食谱里的角色 | 典型用途 |
| --- | --- | --- |
| **电饭煲** | 一锅出、免看管 | 焖饭、粥、蒸架蒸菜、预约早餐 |
| **蒸蛋器** | 早上并行做事的核心 | 蒸蛋、蒸虾、蒸鱼、热包子 |
| **电磁炉** | 温度可控、好清理 | 焯水、批量备餐、煎、煮汤 |
| **燃气炉** | 火力最猛 | 爆炒、白灼、滑蛋 |
| **空气炸锅** | 零油烟、不用刷锅 | 肉类、虾、冷冻蔬菜 |

> **选型口诀**：早上用蒸蛋器（并行），晚上用电饭煲（一锅），想快用燃气炉（爆炒），怕油烟用空气炸锅，批量备餐用电磁炉（焯）。

## 每个食谱文件的结构（新增时照这个来）

1. **先记住几件事**——最关键的安全/失败点，放最前面
2. **认识这个食材**——怎么挑、规格怎么看、营养对照（和手册口径一致）
3. **处理**——解冻/清洗/去腥/分装保存
4. **熟度判断**——怎么算"完成"，以及时间上限
5. **厨具速查**——哪件厨具适合什么做法
6. **早餐方案**——12 分钟以内，含前一晚准备
7. **正餐方案**——午/晚餐，一锅出优先
8. **周末推荐**——值得花时间、能改善坚持率的做法
9. **批量备餐**——一次做、管几天
10. **常见错误**——踩过的坑
11. **一页速查**——打印贴冰箱
12. **一句话总结**

## 命名与链接约定

- 文件名用中文食材名，如 `冻生虾仁.md`、`鸡胸肉.md`
- 每个文件开头用相对路径回链到 `../饮食实操手册.md`，并回链到本文件
- 营养数据（蛋白/热量/分量）**统一以手册 §5 速查表为准**，不另立数字
- 分量口径统一用"蛋白锚点"：1 个锚点 ≈ 25–30g 蛋白（虾仁 150–160g）
