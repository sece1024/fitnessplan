# 山姆采购清单（一人食 · 增肌版）

> 配套：[饮食实操手册.md](饮食实操手册.md)｜[健身计划-调整版.md](../健身计划-调整版.md)
>
> 针对 173cm / 60kg 增肌，一天 4 个蛋白锚点（约 115g 蛋白）+ 300–350g 碳水。
> 山姆自有品牌 **Member's Mark（MM）** 通常是同品质里性价比最高的，同类优先选它。具体包装规格和价格随门店/季节变化，以现场为准。

---

## 一、必买 12 样（照着买就不会错）

| # | 食材 | 建议包装 | 一人食能吃 | 为什么必买 |
| --- | --- | --- | --- | --- |
| 1 | **鸡蛋** | 30 枚级大包装 | 约 10 天 | 6.5g 蛋白/个，最便宜的优质蛋白 |
| 2 | **全脂牛奶** | 200ml×24 或 1L×6 | 2–3 周 | 300ml = 10g 蛋白 + 15g 碳水 |
| 3 | **冷鲜鸡胸肉** | 1–1.5kg | 1–2 周（分装冷冻） | 23g 蛋白/100g，增肌主力 |
| 4 | **鸡腿 / 琵琶腿** | 1kg | 约 1 周 | 去皮 19g/100g，比鸡胸好坚持 |
| 5 | **冷冻虾仁** | 1kg 袋装 | 约 1 个月 | 18g/100g，极低脂、免处理 |
| 6 | **冷冻鱼柳（巴沙/龙利）** | 1kg 袋装 | 约 1 个月 | 无刺、5 分钟熟，救急神器 |
| 7 | **燕麦片** | 1kg 袋装 | 3–4 周 | 50g = 33g 碳水 + 6.5g 蛋白，早餐主力 |
| 8 | **希腊酸奶 / 无糖酸奶** | 大桶或小杯装 | 3–5 天 | 希腊酸奶 200g ≈ 18g 蛋白 |
| 9 | **香蕉** | 一把 | 3–4 天 | 1 根 22g 碳水，练前加餐首选 |
| 10 | **每日坚果 / 原味混合坚果** | 大袋分装 | 约 1 个月 | 每天一小把补好脂肪 |
| 11 | **冷冻西兰花 / 混合蔬菜** | 袋装 | 约 1 个月 | **一人食唯一不会烂的蔬菜** |

**这 12 样覆盖了你 4 个蛋白锚点里除午餐以外的全部食材。**

## 二、分类完整清单

### 🥩 蛋白类

| 食材 | 建议 | 说明 |
| --- | --- | --- |
| 鸡蛋 | ✅ 必买 | 一天 2–3 个完全没问题，蛋黄别扔 |
| 全脂牛奶 | ✅ 必买 | 别买脱脂，增肌期那点脂肪是帮手 |
| 希腊酸奶 | ✅ 必买 | 真希腊酸奶蛋白是普通酸奶的 2–3 倍；**但名字会骗人，见下方挑法** |
| 冷鲜鸡胸肉 | ✅ 必买 | 大包装一定要分装冷冻，见 §四 |
| 鸡腿 / 琵琶腿 | ✅ 必买 | 去皮后蛋白接近鸡胸，但好吃得多 |
| 冷冻虾仁 | ✅ 必买 | 解冻即用，没有厨艺门槛 |
| 冷冻鱼柳 | ✅ 必买 | 巴沙鱼/龙利鱼，无刺、便宜 |
| 三文鱼 | ⭕ 一周 1–2 次 | 好脂肪来源，单价高，不必当主力 |
| 牛排 / 牛里脊 | ⭕ 常备 | 铁和锌高，**精力差、容易累的时候吃** |
| 猪里脊 | ⭕ 常备 | 便宜好做，20g 蛋白/100g |
| 金枪鱼罐头（水浸） | ✅ 常备 | 免煮，加班回家 3 分钟一个锚点 |
| 即食鸡胸（袋装） | ✅ 常备 | 放公司抽屉，17:30 加餐用 |
| 北豆腐 / 豆干 | ⭕ 可选 | 换口味用；北豆腐 12g/100g，豆干 16g |
| 蛋白粉 | ⭕ 非必需 | 只在"差 30g 又没时间吃"时当补丁 |

#### ⚠️ 买酸奶只看两个数字，别看名字

市面上的「希腊风味酸奶」「希腊式酸奶」很多**不是过滤型希腊酸奶**，只是普通酸奶加了奶油和增稠剂（明胶、果胶、淀粉）做出浓稠口感——蛋白一点没提高，糖倒是加了不少。**翻到背面看营养成分表：**

| 指标 | 合格线 | 说明 |
| --- | --- | --- |
| **蛋白质** | **≥ 6g/100g** | 低于这个数，不管叫什么都只是普通酸奶 |
| **碳水化合物** | **≤ 6g/100g** | 超过 10g 基本就是含糖甜品 |

**凑够 1 个蛋白锚点（30g）需要吃多少：**

| 类型 | 蛋白/100g | 要吃的量 | 附带热量 |
| --- | --- | --- | --- |
| 真希腊酸奶（过滤型） | 6–10g | **300–400g** | 200–400 kcal |
| 希腊"风味"酸奶 | 2.5–3.5g | 约 1000g ❌ | 约 1000 kcal |
| 普通无糖酸奶 | 3–3.5g | 约 900g ❌ | 约 650 kcal |

> 结论：**普通酸奶补蛋白是不现实的**——同样 30g 蛋白，你要吃 1kg，顺带 100g 糖。
> 但也不必非买希腊酸奶：**论每克蛋白的价格，牛奶 < 鸡蛋 < 希腊酸奶**。预算紧就喝牛奶，希腊酸奶买的是"换口味 + 方便"，不是必需。

### 🍚 主食碳水

| 食材 | 建议 | 说明 |
| --- | --- | --- |
| 大米 | ⭕ 常备 | 5kg 装太重，顺路去门店带 |
| 燕麦片 | ✅ 必买 | 早餐最省事的碳水 |
| 全麦面包 / 贝果 / 欧包 | ✅ 必买 | 切片冷冻，吃前烤 3 分钟 |
| 挂面 / 意面 | ⭕ 常备 | 番茄鸡蛋面的底子 |
| 红薯 / 玉米 | ⭕ 可选 | 换主食口味，蒸一次吃两天 |
| 香蕉、苹果 | ✅ 必买 | 加餐和练前的主要来源 |
| 冷冻蓝莓 / 混合莓 | ✅ 推荐 | 比鲜果耐放得多，配燕麦正好 |

### 🥦 蔬菜

| 食材 | 建议 | 说明 |
| --- | --- | --- |
| 冷冻西兰花 / 混合蔬菜 | ✅ 必买 | 一人食首选，随取随用不浪费 |
| 胡萝卜、洋葱、番茄、土豆 | ⭕ 常备 | 耐放，一周买一次够用 |
| 生菜、菠菜等叶菜 | ⚠️ 少买 | 一个人吃不完，烂一半是常态 |
| 蘑菇、青椒 | ⭕ 可选 | 耐放度中等，一周内吃完 |

### 🥜 脂肪与调味

| 食材 | 建议 | 说明 |
| --- | --- | --- |
| 原味混合坚果 / 每日坚果 | ✅ 必买 | 每天一小把（约 20g），别敞开吃 |
| 花生酱（无糖） | ⭕ 推荐 | 抹面包，热量密度高，增肌期好用 |
| 特级初榨橄榄油 / 菜籽油 | ⭕ 常备 | 炒菜油每天控制在 1–2 瓷勺 |
| 盐、黑胡椒、生抽 | ✅ 常备 | 有调味才吃得下去，别水煮一切 |
| 冷冻鸡胸腌料 / 黑椒汁 | ⭕ 可选 | 让鸡胸不难吃，是能坚持的关键 |

## 三、别买 / 少买（增肌期最容易翻车的）

| ⚠️ | 原因 |
| --- | --- |
| 大袋零食（薯片、饼干、蛋糕、面包干） | 家里有就会吃，一天能吃掉 500 kcal 的"空热量" |
| 冷冻油炸半成品（鸡块、薯条、炸物） | 看着方便，热量爆表、蛋白可怜 |
| 超大桶冰淇淋 | 同上 |
| 整箱含糖饮料 / 果汁 | 液体热量不占肚子，最容易超标 |
| 大包装叶菜 | 浪费为主，不如买冷冻蔬菜 |
| 5kg 以上大米、大桶油、整箱水 | 太重，去门店顺手带更省事 |

**判断标准只有一条**：这东西是"能吃到蛋白和碳水"，还是"只能吃到油和糖"。

## 四、一人食分装与保存（山姆最大的坑是大包装）

**到家 30 分钟内做完：**

| 做什么 | 怎么做 |
| --- | --- |
| **鸡胸 1.5kg** | 按每份 **130–150g**（≈ 1 个蛋白锚点）分装保鲜袋，**压平排气**再冷冻 |
| 虾仁、鱼柳 | 同样按每份 150g 分装冷冻 |
| 面包 | 切片后冷冻，吃前烤箱/平底锅 3 分钟 |
| 鸡蛋 | 冷藏，**不要洗**（洗了反而容易坏） |
| 大桶酸奶 | 开封后 3–5 天吃完，别超过一周 |
| 牛奶 | 常温避光；开封后冷藏 3 天内喝完 |
| 香蕉 | **别冷藏**，室温放；快熟透时剥皮冷冻，能做奶昔 |
| 坚果 | 分装成每天一小把的量，避免一次吃半袋 |

> **压平排气这一步别省。** 冻成薄片，早上冲水 5 分钟就解冻；冻成一块砖，要等一小时——这一小时就是你放弃做饭、点外卖的原因。

## 五、采购频率建议

| 频率 | 买什么 |
| --- | --- |
| **每周 1 次** | 鸡蛋、牛奶、酸奶、香蕉、苹果、耐放蔬菜（胡萝卜/洋葱/番茄） |
| **每 2 周 1 次** | 冷鲜鸡胸、鸡腿、冷冻虾仁、冷冻鱼柳、冷冻蔬菜（分装后正好够 2 周） |
| **每月 1 次** | 燕麦、坚果、面包（冷冻）、大米、油、调味品、金枪鱼罐头、即食鸡胸 |

**小技巧**：鸡胸、虾仁、鱼柳这类冷冻品**一次买够 2 周**，中间那周就只用补蛋奶水果——采购频率减半，坚持率翻倍。

## 一句话总结

> **每周固定买：鸡蛋、牛奶、希腊酸奶、香蕉。每两周囤：鸡胸、鸡腿、虾仁、鱼柳、冷冻蔬菜。每月补：燕麦、坚果、面包、大米。**
> **其余一律不买——山姆的诱惑不在肉蛋奶，在零食区。**
